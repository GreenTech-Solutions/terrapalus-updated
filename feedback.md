HERE'S THE REALLY IMPORTANT BIT:
The idea of needing lots of stuff isn't bad, but the reward here just doesn't seem worth it without something to use it on, and since this is clearly supposed to be post-gleba, you already have all your defenses set up, so where are you supposed to use the UV lamp if not on Terra Palus itself, but you can't because they're too expensive to make - requiring you to set up defenses to get the UV lamp in the first place..

THE OTHER BIG SUGGESTION I HAVE THAT WOULD CHANGE EVERYTHING:
